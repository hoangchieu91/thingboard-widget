# Sổ tay Hướng dẫn Kỹ sư Hiện trường AMItech

Thư mục này chứa các bản phát hành Widget chính thức đã qua kiểm định chất lượng (QA/QC), được gắn số phiên bản chuẩn mực (`v1.0.0`, `v1.0.1`, `v1.1.0`).

## 📁 Danh sách Widget Sản phẩm (`product/widgets/`)

Kỹ sư hiện trường có thể lấy trực tiếp các tập tin `.json` trong thư mục `widgets/` để Import thủ công vào ThingsBoard qua giao diện Web:
1. Mở ThingsBoard ➔ **Resources** ➔ **Widgets library**.
2. Chọn **Import widget** (biểu tượng mũi tên tải lên).
3. Chọn file `.json` tương ứng phiên bản cần dùng.
